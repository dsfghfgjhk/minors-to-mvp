개인정보처리방침

2군에서 MVP까지가 어떤 정보를 어디에 저장하고 어떻게 쓰는지 안내해요.

1. 회원가입과 수집하지 않는 정보

2군에서 MVP까지는 회원가입이 없고, 이름·전화번호·이메일 같은 개인 식별 정보를 요구하지 않아요. 광고나 방문 분석용 쿠키도 쓰지 않아요.

2. 기기에 저장되는 정보

게임 진행 상황과 설정은 이용자의 브라우저 저장소(localStorage)에만 저장돼요. 서버로 보내지 않으며, 브라우저 데이터를 지우면 함께 사라져요.

  • 게임 저장 데이터(선수 정보, 시즌 기록)
  • 나의 은퇴 기록
  • 소리, 조준 보조, 스윙 세기 같은 설정

3. 랭킹에 올라가는 정보

선수가 은퇴하면 랭킹에 표시하기 위해 아래 정보를 랭킹 서버(Supabase)에 보내고, 랭킹 화면에서 누구나 볼 수 있어요.

  • 게임 안에서 정한 선수 이름, 포지션, 등번호, 아바타 색
  • 소속 팀, 최고 OVR, MVP·개인상·트로피 횟수, 통산 WAR, 시즌 수 등 게임 기록
  • 은퇴한 날짜와 시각
선수 이름에 실명이나 연락처 같은 개인정보를 쓰지 마세요. 랭킹 기록 삭제를 원하면 문의로 선수 이름과 은퇴 날짜를 알려 주세요.

4. 외부 서비스

  • Google Fonts: 글꼴을 불러와요.
  • jsDelivr: 3D 경기 화면을 그리는 three.js 라이브러리를 불러와요.
  • Supabase: 랭킹 기록을 저장하고 불러와요.
  • GitHub Pages, Cloudflare Pages: 웹사이트 파일을 전달해요.

이 서비스들은 접속 과정에서 IP 주소 같은 기술 정보를 처리할 수 있으며, 각 서비스의 개인정보처리방침을 따라요.

5. 문의와 변경

개인정보와 관련한 문의는 문의 페이지로 보내 주세요. 이 방침이 바뀌면 이 페이지와 패치노트에 알려요.

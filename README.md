# 2군에서 MVP까지

고교 1학년부터 은퇴까지 한 야구 선수의 커리어를 시즌 단위로 쌓아 가는 웹 게임입니다.

## 플레이 방법

바로 플레이: https://dsfghfgjhk.github.io/minors-to-mvp/

게임 가이드: https://dsfghfgjhk.github.io/minors-to-mvp/guide.html

`index.html` 하나로 돌아가요. 브라우저로 열어도 플레이할 수 있어요.

## 주요 기능

- **선수 만들기:** 이름, 등번호, 포지션(SP·RP·C·1B·2B·3B·SS·LF·CF·RF), 투타, 고등학교, 얼굴, 플레이 스타일, 훈련 포커스를 정해요.
- **진로:** 고교 → KBO 신인 드래프트(또는 육성선수·대학 진학) → 퓨처스리그 → 1군 주전 경쟁 → 상무 피닉스 입대 → FA·트레이드·포스팅으로 NPB와 MLB 진출
- **시즌 진행:** 전광판에 팀 성적과 내 기록이 실시간으로 올라가요. 시즌마다 승부처가 두 번 오고, 50가지가 넘는 상황 중에서 이닝·점수·주자가 담긴 상황판으로 나와요.
- **큰 경기 3D 직접 플레이:** 한국시리즈 7차전, WBC 결승 같은 경기를 3D 야간 경기장에서 직접 해요. 타구는 속도·발사각에 따라 실제 궤적으로 날아가고, 수비수가 따라가 잡을 수 있는지로 안타·아웃·홈런이 갈려요. 타자 커리어는 타격과 내 포지션 수비를 번갈아 직접 플레이해요. 내 쪽으로 오는 타구를 따라가 잡고 원하는 베이스 버튼을 꾹 눌러 송구해요. (three.js 사용)
- **계약:** 제안서에 계약금, 연봉, 기간, 영입 역할이 나와요. 버튼을 꾹 눌러 도장을 찍으면 계약돼요.
- **비시즌 메시지:** 감독, 코치, 전력분석원, 에이전트가 보내는 메시지 25종에 답장을 골라요.
- **국가대표:** U-18 야구 월드컵, 아시안게임, WBC, 프리미어12. 국제대회에서 활약하면 전 세계에서 한 명만 받는 WBSC 올해의 선수 투표에 올라요. 아시안게임 금메달이면 병역 혜택을 받아요.
- **기록:** 우승·개인상 기록실, 시즌별 성적, 기기별 명예의 전당이 있어요.
- **저장:** 브라우저에 자동 저장되고, 설정에서 저장 코드를 복사해 다른 기기로 옮길 수 있어요.

## 안내

고등학교, 대학교, KBO·NPB·MLB 구단, 대회 이름은 실제 이름을 빌려 왔어요. 각 이름의 권리는 권리자에게 있고, 이 게임은 공식 제휴가 없는 팬 시뮬레이션이에요. 경기 결과, 기록, 계약은 실제와 관계없어요.

## 직접 플레이 타자 AI

변화구는 구종별 횡변화와 낙차를 게임용으로 강조합니다. AI 타자는 시각 처리·반응 지연을 거친 공 위치로 스윙 타이밍과 위치를 예측하며, 스윙을 시작한 뒤에는 예측을 고정합니다. 도착 후 오차를 확인해 경기 안에서 타자별 최근 12개 투구 경험을 갱신합니다. 실제 선수 데이터로 훈련한 모델은 아닙니다.

Node.js에서 `node tests/pitch-ai.cjs`로 구종별 궤적, 관측의 인과성, 반복 투구 학습, 실제 투구 진행 순서를 확인할 수 있습니다.

## 실시간 수비·주루

타구의 바운드·감속, 수비수의 도달 시간, 송구 거리와 포물선, 주자의 가속을 같은 초·미터 단위로 계산합니다. 2루→1루 병살, 외야 중계 송구, 홈 쇄도 태그아웃을 공과 주자의 도착 순서로 판정하고 아웃카운트도 장면 진행에 맞춰 반영합니다. 진행 중 새로고침하거나 자동 진행으로 전환해도 결과를 중복 적용하지 않습니다. 변화구의 게임용 과장은 유지하되 이전보다 줄였습니다.

`node tests/live-baseball.cjs`는 병살·주루사, 제3아웃 득점 제한, 송구 연속성, 아웃카운트 적용 순서와 중복 방지를 검사합니다.

## 주자의 귀루 판단

뜬공의 예상 낙구점과 수비 범위로 포구 가능성을 판단해 짧은 리드 후 귀루합니다. 태그업은 실제 포구와 원래 베이스 재터치 이후에만 시작하고, 추가 진루는 송구 상황을 보고 중간에 멈추거나 마지막 안전한 베이스로 돌아갑니다. 강제 진루와 2아웃 상황은 별도로 처리합니다. 경기 안에서 주루사 경험이 누적되면 다음 판단에 더 큰 안전 여유를 두며, 실제 선수 데이터로 훈련한 모델은 아닙니다.

`node tests/runner-decisions.cjs`는 귀루·태그업의 베이스 재터치, 방향 전환 시 위치·속도 연속성, 상황별 판단과 경험 갱신을 검사합니다.

## 야수 수비 직접 플레이

타자 커리어의 직접 플레이 경기에는 내 포지션 수비 기회가 최대 세 번 포함됩니다. 포수·내야수는 땅볼을 처리하고 외야수는 뜬공의 낙구 지점으로 이동합니다. 타구는 플레이어의 수비 구역으로 오며, 가까이 접근하면 자동으로 포구합니다. 다이빙은 짧은 추가 수비 범위와 일어나는 시간을 갖습니다.

- 이동: WASD·방향키, 화면의 땅 클릭, 모바일 조이스틱
- 다이빙: J 또는 다이빙 버튼
- 송구: 원하는 베이스 버튼 또는 1·2·3·4(홈) 키를 꾹 누르기
- 포구 전부터 누르고 있으면 공을 잡은 뒤 바로 송구합니다. 짧은 탭은 베이스 선택만 하며, 송구 정확도는 선수의 송구·수비 능력에 따라 정해집니다.

포스아웃·태그업 재터치·병살 중계·빗나간 송구를 실제 공과 주자의 도착 시간으로 판정합니다. 수비 결과는 경기 점수에 반영되며, 수비 도중 저장·새로고침·자동 진행으로 전환해도 같은 결과를 중복 적용하지 않습니다.

`node tests/player-fielding.cjs`로 포지션별 타구, 수비 판정, 베이스 길게 누르기 송구, 저장 복구를 확인할 수 있습니다. `tools/verify_fielding_browser.cjs`는 실제 3D 화면과 키보드·모바일 조작을 검사합니다.

## PC 키보드 조작

직접 플레이의 시작·다음 이닝·결과 확인은 Enter로 진행합니다. M은 소리 켜기·끄기, Esc는 누르고 있던 투구·송구 입력 취소입니다. 창을 전환하거나 포커스를 잃어도 충전 중 투구가 저절로 나가지 않습니다.

| 플레이 | 키 | 동작 |
| --- | --- | --- |
| 투수 | WASD / 방향키 | 조준점 이동 |
| 투수 | Shift + 이동키 | 미세 조준 |
| 투수 | 1~4 / 숫자패드 | 보유 구종 순서대로 선택 |
| 투수 | Q / E | 이전 / 다음 구종 |
| 투수 | R | 조준점 중앙으로 |
| 투수 | Space 길게 누르고 떼기 | 힘을 모아 투구 |
| 야수 | WASD / 방향키 | 선수 이동 |
| 야수 | 1·2·3·4(홈) / 숫자패드 길게 | 해당 베이스로 송구, 포구 전 예약 가능 |
| 야수 | J | 다이빙, 가까운 공은 자동 포구 |
| 타자 | Space | 타이밍 타격 |

Tab과 Enter를 이용한 버튼 조작도 지원합니다. `node tests/game-keyboard.cjs`와 `tools/verify_keyboard_browser.cjs`는 조준 방향, 구종 선택, 충전 취소, 수비 입력, 키보드 경기 진행을 검사합니다.


## 선수 검색과 공개 성장 기록

이번 업데이트부터 생성한 선수는 **랭킹 → 선수 검색**에서 이름 일부 또는 고유 선수 코드로 찾을 수 있습니다. 성장 중인 선수도 검색하며, 같은 이름의 서로 다른 캐릭터는 코드로 구분합니다. 기록 화면은 초기·현재 능력치, 시즌별 OVR 전후와 성적, 이적·수상 등의 타임라인을 보여 줍니다. **전체 성장 기록 복사**, **릴스 요약 복사**, **선수 링크 복사**를 제공합니다. 클립보드 권한이 없으면 선택 가능한 텍스트를 표시합니다.

성장 기록은 생성·의미 있는 상태 변경·시즌 종료·은퇴 때 저장합니다. 전체 게임 저장 코드와 RNG·숨겨진 잠재력·댓글은 공개 데이터에 넣지 않습니다. 기존 저장 파일에는 자동으로 공개 기록을 붙이지 않습니다. 인터넷 연결이 끊기면 기기에서 계속 기록하며 재접속·다음 접속에 최신 전체 기록을 다시 전송합니다. 공개 전에 캐릭터 생성 확인 창과 개인정보처리방침에서 안내합니다.

저장 방식과 서버 필터는 [RANKING.md](RANKING.md)를 참고하세요. `node tests/character-journey.cjs`와 `tools/verify_journey_browser.cjs`로 기록 누적, 동명이인·100위 밖 검색, 오프라인 복구, 복사와 공유 링크를 검사합니다.

수비 카메라는 조작 선수 뒤의 3인칭 위치를 유지합니다. 송구 시 도착 베이스 쪽으로 시선만 회전하고, 병살 중계 선수가 공을 놓는 순간 다음 베이스 방향으로 돌아봅니다. `node tests/field-camera.cjs`로 위치 유지와 중계 시선 전환을 확인합니다.
